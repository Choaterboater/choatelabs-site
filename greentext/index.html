GreenText

A massive upgrade over generic text editors, built for network engineers.

macOS / Windows · Rust + React · v0.1.0

Source on GitHub
Public repository

Standard text editors break when you paste massive firewall policies or dump thousands of lines of log files containing weird control characters. GreenText is a standalone desktop text and network configuration editor built specifically for network engineers working with Aruba, Juniper, and Mist.

Why GreenText?

It's a lightning-fast combination of BBEdit and Termius, integrating text manipulation, configuration intent, and remote system management into a single Deep-Slate UI:

  • Monaco Editor Engine: Parsing optimizations specifically built for massive text payloads.
  • Multi-File Workspace: Handles directories gracefully with instant Rust-powered regex search.
  • Text Tools: One-click commands to Pretty Indent configs, Zap Gremlins, Process Duplicate Lines, and normalize case.
  • Regex Pattern Playground: Live-test complex regex patterns with immediate visual feedback on capture groups.
  • Interactive Diff Engine: Compare dirty configs against saved files and cherry-pick lines.

Connected Workflows

GreenText isn't just an offline text editor. It acts as your networking cockpit:

  • SSH Terminal: Drop into a WebGL-accelerated xterm.js terminal to hit remote boxes natively.
  • SFTP Browser: Graphically browse remote file systems over SSH and pull files right into tabs.
  • Encrypted Vault: AES-256-GCM local storage for credentials and API keys.
  • MCP Integration: Spin up Model Context Protocol servers (GitHub, local tools) to securely power AI automation scripts.

We built this because network engineers deserve better tools than generic code editors overloaded with web development plugins.

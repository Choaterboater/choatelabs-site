Project 02 · macOS & Windows

The editor that speaks network.

GreenText is a desktop text and configuration editor built for network engineers. Massive config payloads, multi-vendor awareness, power text tools, and a live terminal — in one Deep-Slate workspace.

macOS & Windows · Tauri Desktop · Rust + React

View source on GitHub

Public repository — build from source with the Tauri toolchain. Signed release builds coming soon.

Built for

Aruba CX Aruba AOS-S Juniper JunOS Mist Firewall policy dumps Log & capture files Generic text & code

What's under the hood

◫

Monaco editor engine

The same editor core as VS Code, tuned for massive text payloads. Paste thousands of lines of config or logs without the app choking.

⚲

Power text tools

One-click Pretty Indent, Zap Gremlins, process duplicate lines, reverse, sort, trim whitespace, and change case — all from the command palette.

‖

Regex pattern playground

Live-test complex patterns with immediate visual feedback on matches and capture groups before you run them across a file.

⇆

Interactive diff engine

Compare dirty configs against saved files, review changes side by side, and cherry-pick lines to keep or discard.

◫

Multi-file workspace

Open whole directories and search across them instantly with Rust-powered regex. Tabs, split view, and fuzzy file jump built in.

〉

SSH terminal

Drop into a WebGL-accelerated xterm.js terminal to hit remote boxes natively, right next to the file you are editing.

📁

SFTP browser

Graphically browse remote filesystems over SSH and pull files straight into editor tabs — no context switching.

🔒

Encrypted vault

AES-256-GCM local storage for credentials and API keys. Nothing leaves the machine unencrypted.

⚯

MCP integration

Spin up Model Context Protocol servers to securely power AI automation against your own tools and data.

No cloud required.

Your configs stay your configs.

GreenText runs entirely on your machine. Files, credentials, and terminal sessions never touch a server you don't control. No accounts, no telemetry, no sync.

No accounts No cloud sync No telemetry Local vault Offline capable
